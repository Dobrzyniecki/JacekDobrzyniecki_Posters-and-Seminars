This repository contains posters and presentations that were publicly exhibited by Jacek Dobrzyniecki.

Home page: https://sites.google.com/view/jdobrzyniecki/home-page

Note: The plots and data used in these documents are not necessarily free of errors (since they may come from earlier, imperfect calculations).
To obtain access to up-to-date research data, go to a given paper, see if the data has been made public, and if not, contact Jacek Dobrzyniecki to ask for the relevant data.
